Part I — The Arduino Family (Items 1–10)

  1. It is the open-source electronics platform built on easy-to-use hardware (boards) and software (IDE).
  2. The most common Arduino board, based on the ATmega328P microcontroller, widely used by beginners.
  3. The Arduino board with 54 digital I/O pins and 16 analog inputs, designed for projects that need many connections.
  4. The round, sewable Arduino board designed for wearable and e-textile projects.
  5. The chip on the Arduino board that stores and executes the uploaded program (e.g., ATmega328P on the Uno).
  6. The official software application used to write, compile, and upload programs to an Arduino board.
  7. The name of a program written for the Arduino board (file extension .ino).
  8. The function that runs once when the board is powered on or reset.
  9. The function that runs over and over again continuously after setup() finishes.
  10. The named connection points on an Arduino (DIGITAL, ANALOG IN, POWER) where components or jumper wires are attached.

Part II — Arduino SIK Components (Items 11–20)

  1. The SIK component that gives off light when electric current flows through it in the correct direction.
  2. The passive SIK component that limits the amount of current flowing in a circuit.
  3. The SIK component with a rotating knob that acts as an adjustable voltage divider (variable resistor).
  4. The SIK sensor whose resistance changes depending on the amount of light that hits it.
  5. The SIK sensor used to measure temperature (commonly the TMP36).
  6. The SIK component that converts electrical signals into sound.
  7. The SIK component that converts electrical energy into rotary motion.
  8. The semiconductor SIK component used as an electronic switch so that a small signal can control a high-current device such as a motor.
  9. The simple SIK input device pressed by the user to open or close a circuit (momentary switch).
  10. The solderless board where SIK circuits are built before connecting them to the Arduino.
