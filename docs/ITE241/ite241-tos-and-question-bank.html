Question Bank

Arduino Part 2

Review Arduino setup and loop functions, libraries, sensors and actuators, analog inputs, potentiometers, single-board devices, and practical circuit tasks.

Resistor Color Code

Review band order, significant digits, multipliers, tolerance bands, 4-band and 5-band decoding, and verification with a multimeter.

Programming with Arduino

Review the guide's five-part organization, development environment, introductory electronics, programming structures, and examples.

Essay prompts and grading

  1. Explain how an Arduino sensor and an actuator work together in a practical circuit. Give one example and describe the role of the program.
  2. Describe how you would identify a resistor value from its color bands and verify that value with a multimeter.

Essay keyword matching is case-insensitive. Each response is evaluated against the rubric concepts for its prompt.
